# Takeone — запись экрана Android / iPhone с паузой

Программа для Windows и macOS: трансляция экрана телефона на компьютер и запись с кнопками
**● Запись**, **⏸ Пауза / ▶ Продолжить**, **■ Стоп и сохранить**. На выходе — один MP4 без пауз.

| Режим | Windows | macOS |
|---|---|---|
| Android по USB | ✅ | ✅ |
| iPhone по USB | — | ✅ |
| iPhone по Wi-Fi (AirPlay) | ✅ | ✅ (нужен `brew install uxplay`) |

Всё нужное (scrcpy, adb, ffmpeg, на Windows — AirPlay-приёмник) уже внутри установщика,
ставить ничего дополнительно не нужно.

---

## Главное окно

Окно можно растянуть или развернуть на весь экран; размер запоминается и не меняется при переключении
вкладок. Если всё не влезает по высоте, середина прокручивается, а главная кнопка внизу всегда на виду.

Сверху — вкладки **Android**, **iPhone · USB** (только Mac), **iPhone · Wi-Fi** и **Монтаж**.
В Android: отметьте телефоны → «Открыть трансляцию». Когда окна телефонов открыты, внизу главного окна
появляется панель записи — **● Запись**, пауза и стоп сразу для всех окон (те же кнопки есть и в каждом
окне телефона), «Закрыть окна» и, если отметить ещё телефон, «Добавить трансляцию».

## Монтаж (вкладка в главном окне)

Вкладка **«Монтаж»** — быстро поправить видео перед отправкой:

- **«Последняя запись»** открывает только что сохранённую запись, **«Открыть…»** — любой MP4 / MOV / MKV.
- **Обрезать начало и конец:** тяните белые ручки на шкале или поставьте бегунок и нажмите
  «Начать отсюда» / «Закончить здесь».
- **Вырезать кусок из середины:** протяните мышью по кадрам на шкале — кусок выделится жёлтым и прямо
  на нём появится кнопка «✂ Вырезать». Вырезанное становится красным и пропускается при просмотре; вернуть
  кусок — ✕ на нём или кнопка с его временем под шкалой. Esc — снять выделение.
- ▶ — посмотреть, что получится (без звука, вырезанные куски пропускаются). Пробел — смотреть/пауза,
  ← → — на секунду (с Shift — на 0,1 с), Delete — вырезать выделенное.
- «Сохранить видео…» — новый файл (исходный не меняется), режется точно по кадрам, звук сохраняется,
  лимит «Видео не больше … МБ» тоже действует.

## Окно трансляции Android

Телефон открывается в отдельном окне справа от главного. Главное окно остаётся открытым: в нём можно
отметить ещё телефон и нажать «Добавить трансляцию» — новое окно встанет рядом, а следующая запись
станет общей. Пока идёт запись, добавлять телефоны нельзя — сначала остановите её.

Если телефон подключился, но картинки нет дольше 8 секунд, в окне появится «Нет изображения» с кнопкой
«Упрощённый режим» (меньше разрешение, затем программное кодирование). Что происходило, пишется
в лог телефона `~/.takeone/logs/android_server_<серийный номер>.log`.

На Mac видео в окне телефона показывается через видеочип (Core Animation) в полном разрешении
Retina — резко и плавно. Если с этим что-то не так, в настройках главного окна выключите
«Чёткая картинка (Retina)» — новые окна будут рисоваться по-старому.

Окно телефона:

- **Панель сверху:** плашка «● Запись» (во время записи — красная с таймером, на паузе — янтарная),
  ⏸ пауза / ▶ продолжить, ■ стоп и сохранить; справа 📷 скриншот и 🔊 звук на компьютере.
- **Панель снизу:** назад, домой, недавние приложения.
- Во время записи вокруг экрана тонкая красная рамка, на паузе — янтарная. При сохранении внизу
  видна карточка с прогрессом (и пометкой, если видео сжимается до лимита) — трансляция при этом идёт.
- Окно всегда ровно по пропорциям экрана телефона, растянуть его нельзя. При повороте телефона окно
  поворачивается само. Размер окна (маленький / средний / большой) — в настройках главного окна.
- Телефоном управляют мышью прямо в окне: клик — касание, перетаскивание — свайп, колесо — прокрутка,
  правая кнопка — «назад», средняя — «домой», с клавиатуры можно печатать.
- Горячие клавиши (Ctrl на Windows, Ctrl или Cmd на Mac): R — запись, P — пауза, S — стоп,
  Shift+S — скриншот, M — звук.
- Скриншоты сохраняются в «Изображения/Takeone», видео — туда, куда выберете (MP4 или MKV).
- Пока включён звук трансляции (Android 11+), динамик самого телефона молчит, а звук идёт на компьютер.
  Кнопка 🔊 выключает его только на компьютере, в записи звук остаётся.

### Сохранение

После «Стоп» открывается окно «Сохранить запись»: название (можно написать своё — например,
«Баг с магазином»), папка и формат. Папка и формат запоминаются для следующих записей, а если файл
с таким названием уже есть, программа предложит «(2)», «(3)»… Кнопка «Удалить запись» — выбросить её.

### Несколько телефонов сразу

Отметьте в списке два телефона (или больше) и нажмите «Открыть трансляцию» — окна откроются рядом.
Как записывать, выбирает переключатель **«Общая запись телефонов»** в настройках:

- **включён** — кнопки записи, паузы и стопа на любом из окон управляют всеми сразу, а результат —
  **одно видео**, где экраны идут рядом слева направо, синхронно, без звука (30 кадров/с);
- **выключен** — у каждого телефона своя запись со звуком и свои кнопки, файлы сохраняются отдельно
  (в имени файла — модель телефона).

Переключать можно и при открытых окнах, пока не идёт запись.

### Лимит размера видео

В главном окне: «Видео не больше … МБ» (по умолчанию 50, 0 — без лимита). Записывать можно сколько
угодно; если при сохранении файл получается больше лимита, он сжимается под него. Длительность
сохраняется, при сильном сжатии уменьшается разрешение (и частота — до 30 кадров/с).
Сжатие идёт в один проход и, где возможно, на видеочипе (Mac — VideoToolbox; Windows — NVIDIA,
Intel, AMD или Media Foundation), поэтому заметно быстрее, чем раньше. Если видеочипа нет или бюджет
битрейта маленький — используется x264, тоже в один проход. Работает для всех режимов, включая iPhone.
Настройки главного окна запоминаются между запусками.

## Как получить установщики (один раз, ~15 минут)

Установщики собираются бесплатно на серверах GitHub — нужен только аккаунт на github.com.

1. Создайте на GitHub новый репозиторий (можно **Private**), например `Takeone`.
2. Загрузите в него содержимое этой папки целиком, **включая скрытую папку `.github`**.
   Проще всего через GitHub Desktop или командами:
   ```
   git init && git add . && git commit -m "Takeone"
   git branch -M main
   git remote add origin https://github.com/<вы>/Takeone.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** → слева **Build** → **Run workflow**.
4. Через 15–25 минут внизу страницы запуска появятся файлы (раздел **Artifacts**):
   - `Takeone-Windows` → `Takeone-Setup-1.0.0.exe`
   - `Takeone-macOS-arm64` → `.dmg` для Mac на Apple M1/M2/M3/M4
   - `Takeone-macOS-x86_64` → `.dmg` для Mac на Intel

**Чтобы раздавать коллегам постоянной ссылкой:** создайте тег версии
(`git tag v1.0.0 && git push --tags`) — установщики сами прикрепятся к странице
**Releases** репозитория, оттуда их можно скачивать и пересылать.

Новая версия: поменяйте `VERSION = "..."` в `app/takeone.py` и поставьте новый тег.

### Собрать на своём компьютере (без GitHub)

- **macOS:** нужен Python с python.org и Xcode Command Line Tools (`xcode-select --install`):
  `bash packaging/build_macos.sh` → `build/Takeone-<версия>-macOS-<arch>.dmg`
- **Windows:** нужны Python и Inno Setup 6 (`winget install JRSoftware.InnoSetup`):
  `powershell -ExecutionPolicy Bypass -File packaging\build_windows.ps1`
  Без MSYS2 сборка пройдёт без режима AirPlay. Чтобы он был, сначала в оболочке MSYS2 UCRT64:
  `bash packaging/bundle_uxplay.sh build-uxplay`, затем `build_windows.ps1 -UxplayDir build-uxplay`.

## Установка (для тех, кому вы отправляете)

**Windows:** запустить `Takeone-Setup-…exe` → Далее → Установить. Если появится синее окно
SmartScreen «Windows защитила ваш компьютер» — **Подробнее → Выполнить в любом случае**
(предупреждение появляется у любой программы без платной цифровой подписи).

**macOS:** открыть `.dmg`, перетащить Takeone в «Программы». При первом запуске macOS скажет,
что не может проверить разработчика: **Системные настройки → Конфиденциальность и безопасность →
внизу «Takeone заблокировано» → Всё равно открыть**. Если пишет, что приложение «повреждено»,
в Терминале: `xattr -dr com.apple.quarantine /Applications/Takeone.app`

## Подготовка телефона

**Android:** Настройки → О телефоне → 7 раз нажать «Номер сборки» → «Для разработчиков» →
включить **Отладку по USB**. При подключении кабелем подтвердить доступ на телефоне.

**Особенности разных марок Android** (Takeone сам подскажет в окне, если упрётся в одну из них):

- **Xiaomi / Redmi / POCO:** для касаний мышью дополнительно включите «Отладка по USB (настройки
  безопасности)» и перезагрузите телефон. Пункт требует вход в Mi-аккаунт и SIM-карту.
- **OPPO / realme / OnePlus:** если касания не работают — «Для разработчиков» → «Отключить мониторинг
  разрешений», затем перезагрузка.
- **vivo / iQOO:** при проблемах с касаниями — «Отладка по USB (настройки безопасности)».
- **Samsung:** если звук не захватывается, Takeone сам переподключится без звука.
- **Huawei / Honor:** при подключении выберите режим USB «Передача файлов»; на части моделей нужно
  включить «Разрешить отладку ADB в режиме "Только зарядка"».
- **Слабые или старые телефоны:** если видеокодер телефона не справляется, Takeone переподключается
  в 1280p, а при повторном сбое — с программным кодированием.
- **Звук:** Android 12+ — сразу; Android 11 — экран должен быть разблокирован в момент подключения;
  Android 10 и старше — без звука (ограничение Android).
- **Русский текст** с клавиатуры компьютера вставляется через буфер обмена телефона (латиница — как
  обычный ввод), поэтому буфер обмена на телефоне при наборе заменяется.
- **Windows:** если телефон не появляется в списке, поставьте USB-драйвер производителя (для Samsung —
  Samsung USB Driver for Mobile Phones, для остальных — Google USB Driver или драйвер с сайта марки).

**iPhone по USB (Mac):** подключить кабелем, разблокировать, «Доверять этому компьютеру».
При первой записи macOS спросит доступ к камере — разрешить (так macOS называет захват видео).

**iPhone по AirPlay:** iPhone и компьютер в одной сети Wi-Fi (не гостевой). В программе режим
«iPhone (AirPlay, Wi-Fi)» → «Подключить», на iPhone: Пункт управления → Повтор экрана → Takeone.

## Если что-то не работает

- Логи: папка `.takeone/logs` в домашней папке пользователя.
- Android: если окно пишет «Устройство отключено», под надписью показана причина с телефона и кнопка
  «Подключить снова». Если телефон оборвал связь в первые секунды (так бывает на некоторых Samsung
  из-за захвата звука), Takeone сам переподключится без звука. У каждого телефона свой лог:
  `android_server_<серийный номер>.log`.
- Android: «Запись не стартовала» — в настройках поставьте «Макс. сторона» 1280.
- AirPlay на Windows: iPhone не видит Takeone — проверьте, что сеть в Windows отмечена как
  «Частная», и что сторонний антивирус не блокирует `uxplay.exe`.
- AirPlay на Mac: «порт занят» — выключите «Приёмник AirPlay» в Системных настройках →
  Основные → AirDrop и Handoff.

## Состав проекта

```
app/takeone.py              главное окно и режимы iPhone
app/android_view.py         окно трансляции Android: экран, управление, запись, скриншоты
app/editor.py               вкладка «Монтаж»: просмотр, обрезка, вырезание кусков
app/mac_video.py            показ видео на Mac через Core Animation (чётко на Retina)
app/save_dialog.py          окно «Сохранить запись»: название, папка, формат
app/ui_kit.py               оформление: цвета, шрифты, иконки, кнопки, переключатели, карточки
app/ios_capture.swift       запись iPhone по USB на macOS
packaging/build_windows.ps1 сборка Windows (PyInstaller + Inno Setup)
packaging/bundle_uxplay.sh  сборка AirPlay-приёмника UxPlay для Windows (MSYS2)
packaging/installer.iss     установщик Windows
packaging/build_macos.sh    сборка .app и .dmg
packaging/make_icon.py      иконка
.github/workflows/build.yml автосборка на GitHub
```

Используемые открытые компоненты: scrcpy (Apache-2.0), ffmpeg (GPL), UxPlay (GPL-3.0), GStreamer (LGPL).
Для внутреннего использования в команде ограничений нет; при публичном распространении
программы прикладывайте ссылки на исходники этих проектов.
